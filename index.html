Button tones

Every Button variant has a tone: accent (the brand colour) or neutral (the same greys in every brand). Ghost has no fill until hover. Disabled looks the same in both tones. Applied to the Figma branch on 2026-09-26.

Hover and pressed are static samples. Buttons in the Default and Disabled columns are live.

Icon buttons next to their Button

IconButton md and sm use Button's size tokens, so they match Button default and sm in every density. xs (16 px) has no Button: it is for inline icons, so only ghost has it. Ghost also has a link tone for icons that open a page: it uses the shared link blue and never takes a fill. It has no Button equivalent, because a text link is used instead.
